# native_api_bindgen (CLI)

`native-api-bindgen` command-line tool. Commands: `init`, `detect`, `doctor`, `inspect`, `generate`, `update`, `diff`, `coverage`, `graph`, `explain`, `why-generated`, `why-skipped`, `audit-license`, `verify-reproducible`, `clean`. Global flags: `--json`, `--verbose`, `--quiet`, `--project`, `--config`.

Exit codes: `0` ok, `1` failure (including license BLOCK), `2` not implemented (E015), `64` usage error.
