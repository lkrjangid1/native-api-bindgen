# Support

- **Questions / usage:** GitHub Discussions.
- **Bugs:** open an issue using the *Bug* template and include `native-api-bindgen doctor --json` output.
- **An API you expected was not generated:** use the *Generator coverage* template and include `native-api-bindgen why-skipped '<symbol>'`.
- **Legal/source concerns:** use the *Legal / source issue* template.
- **Security:** see `SECURITY.md` — do not file public issues.

This is a volunteer-run experimental project; there is no SLA.
