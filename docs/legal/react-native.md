# React Native policy

> **Not legal advice.** This document describes engineering policy. Organizations should perform their own legal review before commercial redistribution.

React Native support is not implemented yet. When implemented it will target the New Architecture (JSI, Turbo Native Modules, Codegen) per https://reactnative.dev.
