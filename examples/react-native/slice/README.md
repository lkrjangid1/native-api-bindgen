# React Native (Android + iOS): native tasks from JavaScript

React Native 0.87 (New Architecture) app. Every native call goes through TypeScript bindings generated by native-api-bindgen. On Android a call goes TypeScript → JSI → C++ → JNI; on iOS it goes TypeScript → JSI → Objective-C++. There is no hand-written TurboModule per API.

The **Showcase** tab (`src/showcase/`) does the same tasks as the Flutter examples:

| Task | Android | iOS |
|---|---|---|
| Live device dashboard | battery broadcast, `ActivityManager.MemoryInfo`, `StatFs`, `ConnectivityManager` | `UIDevice`, `NSProcessInfo`, `NSFileManager` |
| Speak text | `TextToSpeech` + `OnInitListener` implemented in JS | `AVSpeechSynthesizer` |
| Share text | `ACTION_SEND` + chooser | `UIActivityViewController` |
| Copy / paste | `ClipboardManager` | `UIPasteboard` |
| Persistent note | `SharedPreferences` | `NSUserDefaults` (with the runtime's `nsString()` for the `id` value) |
| Feedback | `Vibrator` + guarded `VibrationEffect` | `UIImpactFeedbackGenerator`, `UINotificationFeedbackGenerator` |
| Location settings | `ACTION_LOCATION_SOURCE_SETTINGS`, app permission page (`ACTION_APPLICATION_DETAILS_SETTINGS`) | app page in Settings (`UIApplicationOpenSettingsURLString` value) |
| Open a URL | `ACTION_VIEW` | `openURL:options:completionHandler:` (block → JS function) |

The **Self-tests** tab shows the platform suite (`src/selfTestsAndroid.ts`, `src/selfTestsIos.ts`). The suite runs on launch, covers the showcase tasks and the binding features one at a time, and logs `NAB_TEST …` lines.

The generated library (`native-api-bindings/`) is local-only and not committed.

```sh
# from the repository root
ANDROID_SERIAL=<emulator> tools/run_rn_device_tests.sh    # Android emulator/device (logcat)
NAB_IOS_SIMULATOR=<udid>  tools/run_rn_ios_tests.sh       # iOS simulator (unified log)
```

Both scripts regenerate the bindings (`generate react-native`), type-check, build a release app with bundled JS, launch it and fail on any `NAB_TEST FAIL` or timeout. `npx jest` runs the TypeScript runtime unit tests.

Integration points (all one-time): `codegenConfig` in `package.json` (spec + iOS module provider), `android/app/src/main/jni/{CMakeLists.txt,OnLoad.cpp}`, `NabContext.init(this)` in `MainApplication.kt`, and `pod 'NativeApiBindings'` in `ios/Podfile`.
