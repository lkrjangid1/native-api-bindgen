Examples

The example apps do real work through generated bindings, with no plugin and no hand-written native code: a live device dashboard, text-to-speech, the share sheet, the clipboard, a persistent note, haptics and opening URLs. The same tasks run in Flutter and React Native on Android and iOS, and every task is covered by an on-device test.

    null, IntentFilter.new$String(Intent.ACTION_BATTERY_CHANGED.toJString()))!;

Text-to-speech with a callback

Android reports that the engine is ready through TextToSpeech.OnInitListener, a Java interface implemented here in JavaScript (React Native):

const engine = TextToSpeech.new(applicationContext(), TextToSpeech_OnInitListener.implement(
  { onInit: status => {
      if (status === TextToSpeech.SUCCESS)
        engine.speak$CharSequence$int$Bundle$String(text, TextToSpeech.QUEUE_FLUSH, null, 'id');
  } },
  { async: ['onInit'] },
));

APIs newer than your minimum SDK

VibrationEffect is API 26+, newer than the example's minApi: 24. The generated call checks the device and throws instead of crashing:

try {
  vibrator.vibrate$VibrationEffect(VibrationEffect.createOneShot(60, VibrationEffect.DEFAULT_AMPLITUDE));
} on NativeApiUnavailableException {
  vibrator.vibrate(60);                                  // legacy API on older devices
}
