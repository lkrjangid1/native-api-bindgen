Supported

  • Classes, interfaces, enums, nested types; constructors, static and instance methods, overloads, varargs, fields and exact constants.
  • Nullability from platform and AndroidX annotations; availability guards for APIs newer than minApi.
  • Implementing Java interfaces (Flutter and React Native); Kotlin suspend functions as Dart Futures.

Hidden and non-SDK APIs

A class absent from api-versions.xml is classified as hidden or non-SDK (E006) and never generated, nor are its members. Library jars are not classified this way: their APIs are your library's APIs.
