Getting started

You need the platform SDKs you already use for app development: the Android SDK (with a platform such as android-36) and/or Xcode on macOS. The tool never downloads SDK components.

1. Install

From a checkout of the repository (packages are not published yet):

dart pub global activate --source path packages/native_api_cli
native-api-bindgen doctor

doctor reports the Android SDK, platforms, JDK, Flutter, Xcode, iOS SDK and libclang it finds.

2. Configure

native-api-bindgen init   # writes native_api_bindgen.yaml with safe defaults
platform:
  android:
    platform: "36"
    minApi: 24                  # newer APIs get runtime guards
    entries: [android.content.Intent, android.net.Uri]
    depth: 0
  ios:
    minVersion: "15.0"
    frameworks: [Foundation, UIKit]
    classes: [UIDevice, UIView]
output:
  dir: lib/src/generated
distribution:
  generatedArtifacts: local-only

Generating a whole SDK is never implicit: select entry types, classes, packages or frameworks.

3. Generate

CommandOutput
generate flutterDart over package:jni (Android)
generate iosDart over package:objective_c (+ Swift adapters if configured)
generate react-nativeTypeScript + C++/Objective-C++ runtime library for every configured platform
coverage, why-skipped, explainwhat was generated, what was not, and why

4. Use

Add the runtime dependencies (jni/jni_flutter for Android, objective_c and ffi for iOS) and import the generated library. Complete, tested apps live in examples/: flutter/android_slice, flutter/ios_slice and react-native/slice.
